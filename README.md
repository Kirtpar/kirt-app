# Kirt.app + Estima

This package contains the updated static Kirt.app entry page and the Estima route.

## Files

- `index.html` — existing takeoff app with an **Estima** navigation button.
- `estima/index.html` — self-contained estimating app served at `/estima/`.
- `favicon.png` — existing Kirt.app favicon used by the homepage.

## Publish


- `https://kirt.app/` opens the mechanical takeoff app.
- `https://kirt.app/estima/` opens Estima.

Estima stores saved estimates in browser storage on the current device. Use **Export data** or **Print / PDF** for portable copies.
