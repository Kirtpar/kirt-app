HOW TO USE

  1. Choose a file of an engineered print in the top left. Do not use a picture of prints or the scale will not be correct.
  2. Select the scale and press Apply Scale to Page. Many prints have different scales on different pages, so please verify each page.
  3. Draw Run is used for any sort of duct or pipe run. Use the right-hand menu to select sizes and add information about each run. Each run will be saved in Quick Duct or Quick Pipe for ease of use.
  4. Place Accessory is used to mark any sort of fitting, elbow, accessory, or equipment. Select the type of accessory in the right-side menu.
  5. It is recommended that you use Save As or Ctrl+S to save your work. Save In Browser stores the project in your local browser. Do not use browser storage as a long-term storage area; it is primarily provided for convenience while this app is being developed.
